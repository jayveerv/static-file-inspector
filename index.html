#

Hashes & identity

SHA-1/256/512 for IOC lookups, plus the real type from magic bytes — catches a .exe wearing a .pdf name.

⌗

PE internals

Architecture, compile time, imported DLLs and per-section entropy that exposes packed code.

⊟

Archive X-ray

Lists every file inside a ZIP/JAR/APK/Office doc and flags executables or scripts hidden within.

⚑

IOC extraction

URLs, domains, IPs, emails and wallets pulled out, de-duplicated and exportable as JSON.

◈

PDF objects

Counts active-content objects — /JavaScript, /OpenAction, /Launch — that let a document run code.

▣

ATT&CK mapping

Maps API names and command strings to MITRE techniques, giving you leads to verify fast.
